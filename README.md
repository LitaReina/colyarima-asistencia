# Asistencia Colyarima · Wireframe

Prototipo tipo wireframe, de baja interacción, de una aplicación web para el control de ingreso, asistencia y novedades del Colegio Integrado Yarima (San Vicente de Chucurí, Santander).

**Prototipo en línea:** https://litareina.github.io/colyarima-asistencia/

Actividad 2. Análisis del proyecto para realizar una aplicación web
Electiva I: Diseño de Aplicaciones Web I · Corporación Universitaria Iberoamericana
Autores: Liliana Reina Garzón y Jean Carlos Sandoval Rosas

## Notas

- HTML5 y CSS3 sin dependencias; estilos en `css/wireframe.css`.
- En los campos se puede escribir y seleccionar, pero los datos no se guardan; los botones navegan a la pantalla siguiente del flujo.
- Todos los nombres y datos de estudiantes son ficticios.
